A fundraising platform for WordPress: donation forms, recurring giving, campaigns, and donor records.

== Description ==

Dono is a fundraising platform for WordPress with a block-based donation form builder, one-time and recurring giving, campaigns and funds, encrypted donor records with a self-service portal, receipts, and reporting.

Card payments are processed securely through Stripe using your own connected Stripe account, so donations go directly to you. Offline and manual donations are supported too.

== Installation ==

1. Install Dono from Plugins > Add New, or upload the `dono` folder to `/wp-content/plugins/` and activate it from the Plugins screen.
2. Open **Dono** in the admin menu and follow the short onboarding to set your organisation name and currency.
3. Under **Dono > Settings**, connect Stripe or enable Offline donations.
4. Create a campaign, then add a donation form to any page using the Dono donation form block.

== Frequently Asked Questions ==

= Is Dono free? =

Yes, the plugin is free. Card payments run through your own Stripe account, so your usual Stripe processing fees apply. Dono adds no platform fee of its own, you keep 100% of every donation.

= Which payment methods are supported? =

Stripe (cards) and offline/manual donations.

= Does it support recurring donations? =

Yes. One-time and recurring giving are both built in.

= Where do donations go? =

Straight to your own connected Stripe account. Dono never holds your funds.

= Is donor data secure? =

Donor records are encrypted at rest, and each donor gets a passwordless portal to view their giving history and manage their consent.
